# Geuntae bar

원티드스페이스·flex 근무시간을 macOS 메뉴 막대에 보여주는 앱입니다.

상단 메뉴 막대 아이콘은 근무 기준시간과 관계없이 항상 8칸이며, 기준시간 대비 진행률만큼 채워집니다.
오늘의 달성률은 100%를 넘어 표시합니다. 아이콘은 기준시간을 채울 때마다 초록 → 노랑 → 빨강으로 덧채워지며,
오늘의 최소 목표가 0이거나 없는 날에는 일일 기준시간을 사용합니다. 퇴근 후에는 채움은 회색, 테두리는 달성 구간의 색으로 표시합니다.
달력 옆 **오늘** 달성률과 진행 바는 남은 월 필수시간이나 회사의 일일 근무시간과 무관하게 **항상 8시간 = 100%** 기준입니다.
8시간 이후 노랑, 16시간 이후 빨강으로 왼쪽부터 덧채웁니다.
150%에서는 절반이 노랑, 250%에서는 절반이 빨강이며, 300% 이상에서는 전체가 빨강으로 유지됩니다.

메뉴 막대 아이콘을 누르면 **근무 캘린더**가 열립니다. 날짜를 선택해 근무시간·출퇴근 시각·휴일을 확인하고,
오른쪽에서 오늘의 목표와 월간 누적을 함께 볼 수 있습니다. **오늘** 버튼은 오늘 날짜로 돌아갑니다.
월 이동은 조회된 정산 기간과 진행 중 근무 날짜 범위 안에서 지원하며, 기록이 없는 날짜는 `—`로 구분합니다.
날짜를 바꿔도 창 크기는 고정되며, 긴 월간 요약은 오른쪽 영역 안에서 스크롤합니다.

날짜 아래의 **소정근로시간 인정 제외**(기존 유급)와 **초과근로 산정 반영 제외**(기존 무급) 라디오 중 하나를 선택합니다.
**휴가 없음** 버튼으로 선택을 해제합니다. 날짜 상세·날짜 칸·메뉴 요약의 유급·무급 표시는 유지합니다.
유급·무급 모두 해당 날짜를 남은 근무일에서 제외하고 예정 근무시간만큼 필수·최대 근무시간을 줄입니다.
유급은 수당 기준도 줄이고, 무급은 수당 기준을 유지합니다. 회사에서 이미 휴일·휴가로 반영한 시간은 중복 차감하지 않습니다.
선택은 연동 서비스·계정별로 저장되며 **앱 내 계산에만 반영되고 회사에 휴가를 신청하지 않습니다**.
기존 반복 휴무 설정은 첫 flex 조회 기간의 날짜별 휴가로 한 번만 옮기며, 이후 달에는 반복 적용하지 않습니다.

월간 요약의 **남은 근무일**은 오늘이 근무일이면 퇴근 전까지 오늘을 포함하고, 퇴근 후에는 제외합니다. 휴무·휴가는 제외합니다.
**하루 필요**는 현재까지 반영된 실적을 뺀 남은 월 필수시간을 이 근무일 수로 나누며, 시간·분으로 표시합니다(0.6시간 → 0시간 36분). 분 미만은 올림합니다.
남은 근무일이 없으면 하루 필요는 `—`로 표시합니다. 이 평균은 오늘 진행 바의 고정 8시간 기준과 별개입니다.
미출근 근무일의 **달력 날짜 칸**에는 `-0:54`처럼 **하루 필요**와 같은 평균을 시·분 앞에 마이너스를 붙여 표시합니다. 두 표시 모두 같은 계산값을 사용하며, 분 미만은 올림합니다.
이미 채웠다면 `달성`으로 표시하며, 마우스를 올리면 전체 설명을 볼 수 있습니다.
휴무·휴가·근태 미확인 날짜는 기존 표시를 유지합니다. 각 날짜의 과거 값이 아니라 현재 조회 기간의 하루 평균 필요시간입니다.

## 설치 방법

```sh
git clone https://github.com/SH5H/GeuntaeBar.git
cd GeuntaeBar
./install.sh
```

## flex 재연결

저장된 세션의 자동 갱신이 인증 오류(`400 / AUTH_400_000`)로 거절되면 **flex 재연결이 필요합니다**로 안내합니다.
설정에서 **flex 다시 로그인**으로 연결을 복구할 수 있습니다. 일반 조회 오류나 서버 장애는 기존 로그인을 유지합니다.

로그인 창에서 첫 근태 조회가 실패하더라도 로그인 쿠키가 갱신되면 창을 다시 열지 않아도 연결을 다시 확인합니다.
같은 쿠키로는 조회를 반복하지 않습니다. 네트워크 오류 등으로 실패했다면 로그인 창의 **다시 시도**를 눌러주세요.
